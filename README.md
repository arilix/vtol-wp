# vtol-wp

ROS 2 workspaces for the VTOL waypoint mission and TFmini lidar support.

## Structure

- `waypoint_ws/src/`: PX4 offboard waypoint mission package.
- `tfmini_ws/src/`: TFmini I2C rangefinder package.

Build artifacts such as `build/`, `install/`, and `log/` are intentionally not tracked.
